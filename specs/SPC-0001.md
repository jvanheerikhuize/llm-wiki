# SPC-0001 · Declarative manifest, source ingestion, and deterministic lint skeleton

Tier: **skeleton** · Readiness: **100%**

Establish the file-based knowledge base foundation: a single declarative manifest, immutable source ingestion with cryptographic provenance, and deterministic lint enforcement.

## Non-goals

- Do not require a background database server or external vector store.

## Requirements

### REQ-0001 · Manifest-driven schema and template scaffolding (active)

The knowledge base MUST generate its frontmatter validation schema and per-type page templates from a single declarative manifest and fail validation when committed artifacts drift from the manifest.

**REQ-0001#1**

```gherkin
Given a declarative knowledge base manifest defining base fields and page types
When the scaffolding command is executed
Then the frontmatter validation schema and page templates are regenerated deterministically with zero drift
```

Because:
- FCT-0001 (active): A single declarative manifest prevents schema and template drift

### REQ-0002 · Pluggable source ingestion with immutable raw artifacts and duplicate detection (active)

The ingestion pipeline MUST copy incoming documents into an immutable raw archive, extract text through a prioritized adapter interface, record a content digest on the resulting source page, and warn on near-duplicate sources.

**REQ-0002#1**

```gherkin
Given a new document placed in the ingestion inbox
When the ingestion operation runs
Then the raw artifact is archived immutably, a source page is stamped with its digest, and the inbox is cleared
```

Because:
- FCT-0002 (active): Immutable raw source artifacts with cryptographic checksums preserve provenance

### REQ-0003 · Deterministic linting for schema compliance, link integrity, and confidence caps (active)

The linting operation MUST validate every wiki page against the generated schema, reject broken wikilinks, flag orphan or stale pages, and enforce the maximum confidence cap on unsourced pages.

**REQ-0003#1**

```gherkin
Given a corpus of wiki pages with frontmatter and wikilinks
When the strict lint check runs
Then any schema violation, broken wikilink, or confidence cap breach causes a non-zero exit status
```

Because:
- FCT-0001 (active): A single declarative manifest prevents schema and template drift
- FCT-0003 (active): Unsourced confidence caps and time-based verification windows prevent silent knowledge decay

## Directory Layout

- `.specs/records/` — Hidden atomic epistemic specification records (`ASM`, `FCT`, `QST`, `REQ`, `SPC`).
- `specs/` — Auto-generated agent-facing specifications (`specs/README.md`, `specs/SPC-0001.md`, `specs/SPC-0002.md`).
- `knowledge/manifest.yaml` — Declarative knowledge base schema, confidence policy, lint toggles, and adapter priority.
- `knowledge/tools/` — `kb.py` CLI and subcommands (`scaffold.py`, `new.py`, `ingest_cmd.py`, `search.py`, `lint.py`, `verify.py`, `viz.py`, `purge.py`, `mkdocs_hooks.py`).
- `knowledge/raw/` — Immutable ingested source artifacts.
- `knowledge/wiki/` — Interlinked wiki pages (`sources/`, `entities/`, `concepts/`, `index.md`, `tags.md`).
