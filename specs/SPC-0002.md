# SPC-0002 · Ranked search, claim verification, and interactive knowledge graph visualization

Tier: **feature** · Readiness: **100%**

Builds on: SPC-0001

Layer ranked corpus search, source-bundled claim verification, and the interactive 2D/3D static knowledge graph site with a bolted-on `/specs/` dashboard on top of the core knowledge base skeleton.

## Requirements

### REQ-0004 · Ranked corpus search and source-bundled claim verification (active)

The toolchain MUST provide ranked search across frontmatter and body text with contextual excerpts, and MUST assemble a target page alongside its cited raw sources for claim-by-claim verification.

**REQ-0004#1**

```gherkin
Given a populated knowledge base corpus
When a user or agent queries a term or requests verification for a page identifier
Then ranked matching pages with excerpts or the complete source-backed verification bundle are returned
```

Because:
- FCT-0002 (active): Immutable raw source artifacts with cryptographic checksums preserve provenance
- FCT-0003 (active): Unsourced confidence caps and time-based verification windows prevent silent knowledge decay
- FCT-0004 (active): Compiled wikilink graphs and ranked full-text search enable zero-server traversal

### REQ-0005 · Interactive 2D and 3D knowledge graph visualization and static site publishing (active)

The visualization generator MUST emit a static documentation configuration, a tag index, a connections table, and an interactive 2D and 3D knowledge graph colored by confidence band, published as the primary static site with the specification dashboard mounted at `/specs/`.

**REQ-0005#1**

```gherkin
Given a valid wiki corpus
When the visualization generator runs
Then the homepage graph, connections table, status stylesheet, and static site configuration are generated without broken links
```

Because:
- FCT-0004 (active): Compiled wikilink graphs and ranked full-text search enable zero-server traversal

## Directory Layout

- `.specs/records/` — Hidden atomic epistemic specification records (`ASM`, `FCT`, `QST`, `REQ`, `SPC`).
- `specs/` — Auto-generated agent-facing specifications (`specs/README.md`, `specs/SPC-0001.md`, `specs/SPC-0002.md`).
- `knowledge/manifest.yaml` — Declarative knowledge base schema, confidence policy, lint toggles, and adapter priority.
- `knowledge/tools/` — `kb.py` CLI and subcommands (`scaffold.py`, `new.py`, `ingest_cmd.py`, `search.py`, `lint.py`, `verify.py`, `viz.py`, `purge.py`, `mkdocs_hooks.py`).
- `knowledge/raw/` — Immutable ingested source artifacts.
- `knowledge/wiki/` — Interlinked wiki pages (`sources/`, `entities/`, `concepts/`, `index.md`, `tags.md`).
